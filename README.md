# 🎛️ Toggle Switch UI

Uma interface moderna de botão alternável (Toggle Switch) desenvolvida com foco em simplicidade, interatividade e design minimalista. O projeto apresenta uma animação suave de ativação e desativação, proporcionando uma experiência visual agradável ao usuário.

---

## 📸 Preview do Projeto

Interface contendo:

- Toggle Switch interativo
- Estados de ativado e desativado
- Texto indicativo de status
- Animações suaves
- Design moderno e minimalista
- Layout centralizado

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 🎨 Características do Design

- Interface clean e moderna
- Cores vibrantes e elegantes
- Efeito de sombra suave
- Transições fluidas
- Feedback visual instantâneo
- Layout responsivo
- Experiência intuitiva para o usuário

---

## 🚀 Objetivo do Projeto

Praticar conceitos de manipulação de estados, animações CSS e interatividade com JavaScript através da criação de um componente Toggle Switch moderno e reutilizável.

---

## 📚 Funcionalidades

- Alternar entre os estados ON e OFF
- Atualização dinâmica do texto de status
- Animações suaves durante a transição
- Feedback visual ao usuário
- Estrutura simples e reutilizável
- Compatível com diferentes dispositivos

---

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela:

- Desktop
- Tablet
- Smartphone
